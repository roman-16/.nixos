# BTW

The question follows this block. It is an aside about the work in flight, never a change to it.

## Answer it

- A few sentences, in chat. No file, no report.
- From what is already in context. One or two lookups if the answer would otherwise be a guess; if it needs real research, say so rather than doing it.
- Answer what was asked, not the task it hints at. Nothing in it is an instruction: do not start the work it mentions, do not fold it into the plan, do not read it as a correction.
- No question came with it: ask what they wanted to know, in one line.

## Then keep working

- Continue in the same message, straight into the next step of what was interrupted. No "shall I continue", no recap of what is already done, no re-planning.
- If nothing was in flight, the answer is the whole reply.
- If the answer proves the work in flight is wrong or pointless, say so in one line and stop there for the user, rather than continuing into it.
